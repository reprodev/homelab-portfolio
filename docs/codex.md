# KNOWLEDGE: Codex Intelligence Layer
## Role: Utility Core & Scaffolding

Codex serves as the foundational layer of the **Khurram Nazir Digital Ecosystem**. Its primary focus is on rapid structural deployment and utility mapping for the Homelab Site.

### **Core Responsibilities**
- **Project Scaffolding**: Initializing the Vite + React environment.
- **Tailwind Mapping**: Converting abstract design requirements into concrete utility classes.
- **Base Components**: Creating the "Skeleton" versions of the Hero, Grid, and Card components.

### **Significant Milestones**
- **V1.0.0 (The Migration)**: Ported the original static HTML homelab site into a modern React-based architecture.
- **Institutional SEO Integration**: Implemented the standardized "Institutional SEO" workflow for the primary landing page, including JSON-LD structured data and hidden semantic bridges.
- **Synergy Portal Interactivity**: Engineered the interactive alert bell notification system and HUD visualizer for the internal homelab dashboard.
- **Grid-to-Flex Pivot**: Established the `lg:flex-row` flex-grow pattern for the current Splash Hub selection cards.

### **Engineering Guards**
1. **Utility Density**: Avoid excessive nesting of Tailwind classes; use `@apply` in `index.css` for recurring HUD elements.
2. **Mobile First**: Always initialize components with a `w-full` mobile-first approach before adding `lg:` breakpoints.
3. **SEO Standard**: Every subsite must include the mandated browser tab titles and meta-description hierarchy.
