### **Engineering Guards**
1. **State Isolation**: Keep stage logic contained within the `SplashHub` component to avoid polluting the global `App` state.
2. **Branding Sync**: All portal entries must adhere to the horizontal signature gradient (`Azure-Light` → `White` → `AmberGold`).
3. **Hook Integrity**: Always cleanup event listeners in `useEffect` to prevent memory leaks during viewport resizing.
4. **Mobile Coordinate Gates**: Never compute mouse coordinates dynamically on touch screen viewports; enforce strict `isMobile` check gates.
5. **Interactive Layer Tabbing**: Force scrollable terminal shells and click actions to have `relative z-20` positioning to sit on top of passive CRT overlays (`z-10` with `pointer-events: none`).
6. **Double-Channel Sync Integrity**: Always run backchannel CLI log simulator timers even when the user is toggled to the "GitOps Pipeline" graphic tab. This ensures detailed textual and visual state parameters remain in perfect lockstep.
7. **Ultra-Fine Noise Thresholds**: Never raise the `.noise-overlay` SVG `<rect>` opacity above `0.01` to prevent dulling the visual contrast of active text. Keep noise fine and transparent (`0.008`).
8. **High-Contrast Text Boundaries**: Body paragraph elements must stay at or above `text-slate-300` and use glowing dropping shadows (`drop-shadow-[0_0_8px_...]`) for active indicators to pop spectacularly against the OLED floor.
9. **Tac-Audio Synthesis Protocols**: Standard click/toggle actions must trigger the local synthesized mechanical oscillator (`playSynthesizedSound`) to deliver premium skeuomorphic auditory feedback without importing heavy media files.
10. **Audio Ramp Guards**: Volume mutations and hum state transitions must utilize `linearRampToValueAtTime` or `exponentialRampToValueAtTime` over a $0.15\text{s}$ duration to prevent digital clipping or clicking pops in the browser.
11. **SVG Topology Anchoring**: All network and GitOps workflow paths must be absolute SVG elements with dynamic animators. Avoid raw HTML CSS line connectors that lack high-fidelity trace rendering.
